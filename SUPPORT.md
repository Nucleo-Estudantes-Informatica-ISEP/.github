# Support

For general questions about an NEI-ISEP project, first check that repository's README, documentation and existing issues.

## Bugs and feature requests

Use the repository's GitHub Issues when the repository has issues enabled. Please include enough context to reproduce a bug and avoid posting credentials, access tokens, private student data or other sensitive information.

## Operational or organization support

For questions that are not appropriate for a public issue, contact the Informatics Department at [informatica@nei-isep.org](mailto:informatica@nei-isep.org).

## Security

Do not disclose vulnerabilities or secrets in public issues. Follow the organization [Security Policy](./SECURITY.md) or a repository-specific `SECURITY.md` when present.

Support is provided on a best-effort basis for actively maintained projects. Archived repositories and historical event websites may no longer receive fixes.
